PDF Page Editor

Chrome拡張機能 · MIT License

PDFのページの並べ替え・削除・回転・結合や、ファイルサイズの圧縮が、無料でできるChrome拡張機能です。

  • PDFはインターネットに送られず、お使いのパソコンの中だけで処理されます
  • インストール後はオフラインでも使えます
  • 元のファイルは書き換えず、編集結果を新しいPDFとして保存します
導入手順・ダウンロード →はじめての方はこちら。Windows・Mac別に、5分ほどで使えるようになる手順を説明しています。 要件定義書 →目的・機能・構成・テスト・運用をまとめた開発資料です。 ソースコード（GitHub） →リリース一覧・更新履歴もこちらから確認できます。
