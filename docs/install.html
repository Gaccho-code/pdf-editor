PDF編集ツールを使えるようにする手順

PDFのページの並べ替え・削除・回転・結合が、無料でできるようになります。作業は最初の1回だけで、5分ほどで終わります。上から順番に進めてください。

必要なもの：Google Chrome 所要時間：約5分
お使いのパソコンを選んでください：

導入する（最初の1回だけ）

1

ファイルをダウンロードする

  1. 下の ダウンロード ボタンを押します。
  2. pdf-editor.zip というファイルがダウンロードされます。

ダウンロード（pdf-editor.zip）

ダウンロードしたファイルは、ふつうは「ダウンロード」フォルダに入ります。

2

ファイルを展開して「ドキュメント」に置く

  1. 「ダウンロード」フォルダを開きます。
  2. pdf-editor.zip を右クリックし、すべて展開 を選びます。
  3. 展開 ボタンを押します。pdf-editor というフォルダができます。
  4. そのフォルダを開くと、中にもう1つ pdf-editor フォルダがあります。
  5. この中のほうの pdf-editor フォルダを、左側の ドキュメント にドラッグして移動します。
  1. Finderで「ダウンロード」フォルダを開きます。
  2. pdf-editor.zip をダブルクリックします。pdf-editor フォルダができます。
  3. この pdf-editor フォルダを、左側の 書類 にドラッグして移動します。
大事：このフォルダは、ツールを使っている間ずっと必要です。移動したり削除したりしないでください。動かすとツールが使えなくなります。
3

Chromeの「拡張機能」画面を開く

  1. Google Chromeを開きます。
  2. 下の文字をコピーボタンでコピーし、Chromeの一番上のアドレス欄（いつもURLが表示されている所）に貼り付けて、Enterキーを押します。
chrome://extensions

うまくいかない場合：Chrome右上の ⋮ → 拡張機能 → 拡張機能を管理 でも同じ画面が開きます。

4

「デベロッパー モード」をオンにする

画面の右上にある デベロッパー モード のスイッチを押して、オン（青色）にします。

拡張機能デベロッパー モード
（すでに入っている拡張機能の一覧）

画面の見本です。実際の画面とは見た目が少し違います。

5

ツールを読み込む

  1. オンにすると、画面の左上にボタンが並びます。パッケージ化されていない拡張機能を読み込む を押します。
  2. フォルダを選ぶ画面が開きます。ドキュメント書類 の中の pdf-editor フォルダを1回クリックして選びます（開かなくて大丈夫です）。
  3. フォルダーの選択選択 ボタンを押します。
  4. 一覧に PDF Page Editor が出てくれば成功です。
パッケージ化されていない拡張機能を読み込む拡張機能をパック更新
ドキュメント書類
　📁 pdf-editor　← これを選ぶ
6

ボタンをツールバーに出しておく

  1. Chromeの右上にある 🧩（パズルのピースの形）を押します。
  2. 一覧の PDF Page Editor の横にある 📌（ピン）を押します。
  3. 右上に青いアイコンが出れば、導入は完了です。

最後に、デベロッパー モード はオンのままでかまいません。

使い方

右上の青いアイコンを押すと、編集画面が新しいタブで開きます。

① PDFを開く

PDFファイルを画面にドラッグします。2つ以上入れると、1つにつながります。

② 編集する

ページをドラッグして順番を入れ替えます。ページにマウスを乗せると、回転と削除（✕）のボタンが出ます。

③ 保存する

右上の「PDFを保存」を押すと、「ダウンロード」フォルダに保存されます。元のファイルはそのまま残ります。

ページが小さくて見づらいときは、上の －／＋ ボタンで表示の大きさを変えられます。間違えたときは、上の ↶ ボタンで1つ前に戻せます。PDFはインターネットに送られず、このパソコンの中だけで処理されます。

困ったとき

「マニフェスト ファイルが見つからないか読み取れません」と出た

選んだフォルダが1つずれています。手順5で、pdf-editor という名前のフォルダを選び直してください。

  • Windowsでは、展開してできた pdf-editor フォルダの中にある、もう1つの pdf-editor を選びます。手順2で ドキュメント に移したものを選んでください。
「パッケージ化されていない拡張機能を読み込む」ボタンが見つからない

手順4の デベロッパー モード がオフになっています。右上のスイッチを押してオン（青色）にしてください。

ある日、急に使えなくなった（アイコンが消えた、エラーが出る）

pdf-editor フォルダを移動・削除していないか確認してください。消してしまった場合は、手順1からやり直してください。

「デベロッパー モードの拡張機能を無効にする」という表示が出た

右上の ✕ で閉じてください。無効にする を押すとツールが止まります。押してしまった場合は、手順3の画面で PDF Page Editor のスイッチをオンに戻してください。

開けないPDFがある

パスワードがかかっているPDFは開けません。パスワードを外したPDFでお試しください。

新しい版が出たときは？
  • 手順1の ダウンロード ボタンから新しいZIPをダウンロードし、手順2と同じように展開します。
  • ドキュメント（Macは 書類）の中の古い pdf-editor フォルダを、新しいものに入れ替えます。
  • 手順3の画面で、PDF Page Editor の欄にある ↻（再読み込み）ボタンを押します。
わからないときは、このツールを案内した社内の担当者までお気軽にどうぞ。画面の写真（スクリーンショット）を送ってもらえると早く解決できます。
