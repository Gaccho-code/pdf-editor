PDF Page Editor

プライバシーポリシーと利用規約

PDF Page Editor（Chrome拡張機能版・Web版）が扱う情報と、利用にあたっての条件を説明します。

プライバシーポリシー

PDFの内容

  • 読み込んだPDFは、利用者のブラウザの中だけで処理します。開発者や第三者のサーバーに送信することはありません。
  • Googleドライブから開いた場合、PDFは Google ドライブから利用者のブラウザへ直接読み込まれます。「ドライブに保存」を選んだ場合は、ブラウザから Google ドライブへ直接保存されます。
  • 編集中のPDFはブラウザのメモリにだけ置かれ、タブを閉じるか「クリア」を押すと消えます。

Googleアカウントとドライブへのアクセス

  • Googleドライブ連携では、Google のログインを使います。ツールが受け取るのは、ドライブにアクセスするための一時的な許可（アクセストークン）だけで、パスワードは受け取りません。
  • 要求する権限は drive.file のみです。利用者が「アプリで開く」で選んだファイルと、このツールで保存したファイル以外にはアクセスできません。
  • アクセストークンはブラウザのメモリにだけ置かれ、保存や送信はしません。

そのほかの情報

  • アクセス解析や広告のための情報（Cookieなど）は使いません。
  • 表示倍率の設定だけを、利用者のブラウザ内（localStorage）に保存します。
  • Web版と資料は GitHub Pages から配信しています。配信の際、GitHub がアクセス元のIPアドレスなどを記録することがあります（GitHub のプライバシーに関する声明）。PDFの内容が GitHub に送られることはありません。

  • 元のPDFは変更せず、編集結果は常に新しいファイルとして保存します。
