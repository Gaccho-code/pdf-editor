Googleドライブの「アプリで開く」に PDF Page Editor を追加する手順

Google Workspace の管理者（または管理者の許可を得たアカウント）が、最初に1回だけ行う設定です。所要時間は30〜60分ほどです。設定が終わると、社員はドライブでPDFを右クリック →「アプリで開く」→「PDF Page Editor」で編集できるようになり、インストール作業はいりません。

注意：Google の管理画面は、項目の名前や場所がときどき変わります。この手順と表示が違う場合は、近い名前の項目を探してください。

全体の流れ

  1. A. Google Cloud にプロジェクトを作り、ログインの設定をする → クライアントIDを開発担当に伝える
  2. B. ドライブの「アプリで開く」に表示する設定をする
  3. C. Google Workspace Marketplace に社内限定で登録する
  4. D. 管理コンソールから社員に配布する
  5. E. 動作を確認する

このツールが扱うデータと権限

  • PDFは「Googleドライブ ⇔ 利用者のブラウザ」の間で直接やり取りされます。開発者や第三者のサーバーは通りません。
  • 求める権限は drive.file だけです。これは利用者が「アプリで開く」で選んだファイルと、このツールで保存したファイルにだけアクセスできる、最も範囲の狭い権限です。ドライブ全体は見られません。
  • OAuth の同意画面を「内部」にするため、G&N のアカウントでしか使えません。
  • ツールのプログラムは gaccho-code.github.io/pdf-editor/app/ から配信されます。ページには「このサイト自身と Google 以外とは通信しない」という制限を入れています。

A. Google Cloud の設定

  1. Google Cloud コンソールに、G&N の Google アカウントでログインします。
  2. 画面上部のプロジェクト選択 → 新しいプロジェクト を押し、次のとおり入力して 作成 します。
    • プロジェクト名：PDF Page Editor
    • 組織：G&N のドメイン（個人のアカウントや「組織なし」では、手順4の「内部」が選べません）
  3. 左のメニュー APIとサービス → ライブラリ で次の2つを検索し、それぞれ 有効にする を押します。
    • Google Drive API
    • Google Workspace Marketplace SDK
  4. OAuth の同意画面を設定します（メニューでは Google Auth Platform、または APIとサービス → OAuth 同意画面）。
    • アプリ名：PDF Page Editor
    • ユーザー サポートメール：管理者のメールアドレス
    • 対象（User Type）：内部
    • 連絡先メールアドレス：管理者のメールアドレス
  5. データアクセス（または スコープ）で スコープを追加 を押し、次の1つだけを追加して保存します。
    • https://www.googleapis.com/auth/drive.file
  6. クライアント（または 認証情報 → 認証情報を作成 → OAuth クライアント ID）で、次のとおり作成します。
    • アプリケーションの種類：ウェブ アプリケーション
    • 名前：PDF Page Editor Web
    • 承認済みの JavaScript 生成元：https://gaccho-code.github.io
    • 承認済みのリダイレクト URI：空欄のまま
  7. 作成後に表示される クライアントID（…apps.googleusercontent.com で終わる文字列）を開発担当に伝えます。開発担当がツールに設定して公開します。
    クライアントシークレットは伝えないでください。このツールでは使いません。クライアントIDは公開しても問題のない値です。

B. ドライブの「アプリで開く」に表示する設定

  1. APIとサービス → 有効な API とサービス → Google Drive API を開き、ドライブの UI 統合（Drive UI integration）タブを選びます。
  2. 次のとおり入力して保存します。
    項目入力する内容
    アプリケーション名PDF Page Editor
    短い説明PDFのページの並べ替え・削除・回転・結合・圧縮
    アプリケーション アイコン下のアイコンをダウンロードして、求められたサイズのものをアップロード
    URL を開く（Open URL）https://gaccho-code.github.io/pdf-editor/app/
    デフォルトの MIME タイプapplication/pdf
    デフォルトのファイル拡張子pdf
    ファイルの作成（Create with）設定しない（チェックを外す）
    共有ドライブのサポートオン
  3. アイコン（クリックでダウンロード）：
    32×32 96×96 128×128 256×256

C. Marketplace に社内限定で登録する

  1. APIとサービス → Google Workspace Marketplace SDK → アプリの構成 で、次のとおり設定して保存します。
    • アプリの公開設定：非公開（G&N のユーザーのみ）
    • インストール設定：管理者のみインストール
    • アプリの統合：ドライブ アプリ にチェック
    • OAuth スコープ：https://www.googleapis.com/auth/drive.file（画面の案内で drive.install の追加を求められた場合は、それも追加）
    • デベロッパー情報：管理者の名前・メールアドレス
  2. ストアの掲載情報 で、次のとおり入力して 公開 します（社内限定なので、Google の審査はありません）。
    項目入力する内容
    アプリ名PDF Page Editor
    概要PDFのページの並べ替え・削除・回転・結合・圧縮を、ブラウザの中だけで行うツール
    詳しい説明Googleドライブで右クリック →「アプリで開く」から、PDFのページの並べ替え・削除・回転・結合・ファイルサイズの圧縮ができます。PDFは利用者のブラウザの中だけで処理され、外部のサーバーには送信されません。編集結果は元のPDFと同じフォルダに新しいファイルとして保存でき、元のファイルは変更されません。
    カテゴリ仕事効率化
    アイコン128×128 と 32×32（B のアイコンと同じ）
    スクリーンショットツールでPDFを開いた画面を1枚以上（1280×800 など、画面の指定サイズで撮影）
    サポート URLhttps://gaccho-code.github.io/pdf-editor/
    プライバシー ポリシー URLhttps://gaccho-code.github.io/pdf-editor/privacy.html
    利用規約 URLhttps://gaccho-code.github.io/pdf-editor/privacy.html#terms

D. 管理コンソールから社員に配布する

  1. Google 管理コンソールを開き、アプリ → Google Workspace Marketplace アプリ → アプリリスト を開きます。
  2. アプリを追加 → 社内アプリ（または ドメインにインストール）から PDF Page Editor を選びます。
  3. 管理者によるインストール を選び、対象を 組織全体（または対象の部署）にして、表示される権限（drive.file）に同意します。
  4. 社員のドライブに表示されるまで、数分〜最大24時間かかることがあります。

E. 動作を確認する

  1. ドライブでPDFを右クリック → アプリで開く → PDF Page Editor を選びます。
  2. 新しいタブでツールが開いたら、ドライブから読み込む を押します。初回だけ Google アカウントの確認画面が出るので、続けて進めます。
  3. ページが表示されたら、1ページ削除して ドライブに保存 を押します。
  4. 元のPDFと同じフォルダに 元の名前_edited.pdf ができていれば完了です。
うまくいかないとき
  • 「アプリで開く」に出てこない：D の配布から時間がたっていない可能性があります。数時間おいて、ドライブを再読み込みしてください。
  • 「ドライブから読み込む」で何も起きない：ブラウザがポップアップをブロックしていないか確認してください。
  • 「設定がまだ完了していません」と表示される：A の手順7のクライアントIDが、まだツールに設定されていません。開発担当に連絡してください。
